Comment ça fonctionne

Extraction

Le système analyse l'image pour détecter les données cachées dans les bits les moins significatifs.

Déchiffrement

Une fois les données extraites, le système utilise votre mot de passe pour déchiffrer le document PDF avec l'algorithme AES.

Important

Si le mot de passe est incorrect ou si l'image ne contient pas de PDF caché, le déchiffrement échouera.

Conseils

  • Assurez-vous d'utiliser exactement le même mot de passe que celui utilisé lors du chiffrement.
  • L'image ne doit pas avoir été modifiée ou compressée après le chiffrement.
  • Si vous rencontrez des erreurs, vérifiez que vous utilisez la bonne image et le bon mot de passe.
  • Téléchargez immédiatement le PDF déchiffré, car il pourrait être supprimé du serveur après un certain temps.
